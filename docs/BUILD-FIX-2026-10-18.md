# Build hotfix — October 18, 2026

This package repairs errors copied from the user's actual `ng build` output.

## Repaired

- Replaced unescaped literal `@` tokens in four Angular templates with the HTML entity `&#64;`:
  - `src/app/features/explore/explore.component.ts`
  - `src/app/features/people/people.component.ts`
  - `src/app/features/profile/profile.component.ts`
  - `src/app/shared/post-card.component.ts`
- Implemented `SocialApi.followersPending()` with an authenticated-user scoped query to `follows`, including the referenced profile information.
- Removed the dependency of `npm test` on the Node `--experimental-strip-types` flag. The test now compiles its TypeScript-only test targets with `tsc` before importing them, using either the locally installed TypeScript CLI or a global one.
- Added `tests/angular-template-regression.test.mjs`.

## Verification performed

- `npm test`: 54 passing tests, 0 failing using Node.js 22.16.0 and TypeScript available globally in the execution environment.
- Static review confirms every `this.api.<method>` call in `social-workspace.component.ts` has a corresponding method.
- **`npm run build` is not verified** in this environment; Angular dependencies were not available to run the Angular compiler. Users should run `npm install && npm run build` locally and share any remaining build errors.
- Supabase backend operations, Row Level Security and production browser behavior were **not verified** in this hotfix.

## Run locally

```
npm install
npm test
npm run build
npm start
```
