# Moments Studio Functional Web — development build

Angular browser app with demo pages and separate cloud-backed functionality. Read `docs/IMPLEMENTATION-STATUS.md` before production use.

Run `npm install && npm start`. Use `/cloud` to configure Supabase (publishable key only). Apply `supabase/migrations/001_social.sql` to a **new, disposable Supabase project only** after reviewing its policies.

The project is NOT Instagram-complete and NOT production-security verified.
